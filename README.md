Welcome to my react-mastermind project.

-What's this repository?-

This project is my first React Typescript application project.
I've used it to learn how to create with React.

-What's the goal?-

This application is a game based on Mastermind.
The goal is to find the secret password of the session to access the secret datas of a famous video game company.

-Can you use this repository?-

This repository is under Creative Commons Zero v1.0 Universal, please refer to the LICENSE file in main branch for more informations.

-What I've used and Why?-

To build this app, I've used Vite framework to run my app locally, Visual Studio Code IDE to managed code.
I've followed the React documentation available here : https://react.dev/learn and get some help from ChatGPT and Github Copilot.
ChatGPT was used as a support of the documentation to help me understand React principles and find CSS properties to apply to my elements.
Github Copilot was used to speed up autocompletion.
